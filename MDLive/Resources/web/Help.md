# MDLive Help

A live Markdown previewer. Open a `.md` file and it re-renders whenever the file changes on disk.

## Shortcuts
- **⌘O** Open · **⌘R** Refresh · **⌘W** Close
- **⌘F** Find · **⌘G / ⇧⌘G** Next / previous match
- **⌘+ / ⌘- / ⌘0** Zoom in / out / reset
- **⌥⌘1** Toggle the outline sidebar
- **⌘L** Copy file path · **⌘⇧R** Reveal in Finder
- **⌃⌘T** Keep window on top
- **⌘P** Print · Export as PDF / HTML from the File menu

## Settings (⌘,)
Theme (Dark / Light), content width, font scale, auto-refresh + polling speed, LaTeX math, and a custom CSS file.

## Notes
- MDLive never edits your file — it's preview-only.
- Everything runs offline; there are no network calls.
